This program uses pytubefixed and moviepy to download, then combine YouTube videos into a MP4 video for archiving. It also has a function to download only the audio in mp4a, mp3, and waw formats.
To run the program you'll need Python, pytubefixed, and moviepy installed. Without those, this program simply just won't function. 

I made this program over the course of 3ish days as a "fun" project after my Music Quiz Auto Checker program, which used so much of my brain power.
I'd also grown extremely frustrated with YTDLP as it felt extremely unreliable and clunky to use, especially for people who aren't as tech savvy. I plan on making this into a runnable .exe file eventually, but I am not in a rush to get to it.
There is plenty of code comments, the main chunk of code in regards to Tkinter wasn't made by me but also, it's really ugly so I don't care. Feel free to make a better interface! 

I might come back to fix things as they break, but I can't promise anything. 
Hope you have fun using my program, and it can help you save some important videos!

To run the program, either run the .exe install the various dependencies and run it through Python.

Little fyi, the download is VERY cpu intensive, so just be prepared for that if you are downloading in anything above 1080p.
